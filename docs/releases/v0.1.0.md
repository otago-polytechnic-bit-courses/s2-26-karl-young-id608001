# Release v0.1.0

## Features Delivered

- Set up the Django backend and React Native application.
- Implemented user registration.
- Created the login screen.
- Configured JWT authentication.
- Created the login and register API endpoints.
- Implemented user account management.
- Users can log in and access their own library.
- Added navigation between the main screens of the application.

## Known Issues

- Users cannot upload books yet.
- Books cannot be opened or read in this release.
- The library is currently limited to user authentication and account-specific data.

## Running Locally

### Backend

```bash
cd TookABook_backend

python -m venv venv

venv\Scripts\activate

pip install -r requirements.txt

python manage.py migrate

python manage.py runserver 0.0.0.0:8000
```

### Frontend

```bash
cd TookABook-app

npm install

npx expo start -c
```

**Run using:**

- Android Emulator
- Expo Go
- Physical Android device

### Technical Information

- Backend is built using Django REST Framework.
- Frontend is built using React Native and Expo.
- Authentication uses JWT tokens.
- User libraries are linked to authenticated accounts.
- Navigation structure has been implemented to support future features.
- This release establishes the foundation for uploading and reading books in later sprints.
