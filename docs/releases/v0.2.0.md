# Release v0.2.0

## Features Delivered

- Upload books using the Upload screen.
- Open and read uploaded books.
- Support for PDF and CBZ files.
- Library screen for viewing uploaded books.
- Home screen with Recently Added section.

## Known Issues

- Large books may fail to upload depending on device memory.
- CBZ support has only been tested with smaller files.

## Running Locally

### Backend

```bash
cd TookABook_backend

python -m venv venv

venv\Scripts\activate

pip install -r requirements.txt

python manage.py migrate

python manage.py runserver 0.0.0.0:8000

```

### Frontend

```
cd TookABook-app

npm install

npx expo start -c 
```

**Run using:**

Android Emulator
Expo Go
Physical Android device

### Technical Information

- Backend built using Django REST Framework.
- Authentication handled using JWT.
- Frontend built using React Native and Expo.
- Uploaded books are stored using Django media storage.
- Book metadata includes title, author, genre, cover image, upload date and file type.
