
## Sprint 1 - Core User Access

**Goal:**
- Users can create an account, log in and upload books to their personal library.

### Requirements:

- Registration
- Login and Access Library
- Upload Books

These must come first because everything else depends on users existing and books existing.

---

## Sprint 2 - Reading Functionality

**Goal:**
- Users can open and read books stored in their library.

### Requirements:

- Open Books
- Library View Improvements
- Basic Reader Interface

These depend on books already being uploaded.

---

## Sprint 3 - User Experience Features

**Goal:**
Users can manage and continue their reading experience.

### Requirements:

- Remember Reading Progress
- Bookmarks
- Search Books


These depend on users already being able to read books.

---

## Sprint 4 - UAT

**Goal:**
The application has been tested with users, and the identified issues have been resolved.

### Requirements:

- User Acceptance Testing
- Feedback Collection
- Bug Fixes
- Retesting

This is why your lecturer said to put UAT second-to-last or leave time afterwards. You need time to fix issues found during testing.
